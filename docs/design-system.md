# Design System — основа стиля

> Источник: основной сайт-лендинг **[velizhanin.com](https://velizhanin.com/)** (сделан на Tilda, проект `project741459`).
> Значения ниже сняты напрямую из инлайн-стилей и CSS лендинга 2026-06-09. Это референс, на который опирается дизайн нашего проекта (creative-chat / VELIZHANIN AI).

## TL;DR характер

Чистый светлый минимализм с **одним тёплым акцентом — оранжево-красным `#EC582E`**. Крупная плотная типографика (жирный grotesque, очень тесный интерлиньяж, отрицательный трекинг), много воздуха, сильно скруглённые элементы (pill-кнопки), упор на большие цифры и результаты. Без UPPERCASE, без градиентных пестрот — контраст строится на чёрном тексте по белому + рыжий акцент.

## 1. Цвета

### Основная палитра (по ролям)

| Роль | HEX | Заметки |
|---|---|---|
| **Акцент / бренд** | `#EC582E` | Оранжево-красный. Заливка CTA-кнопок (текст белый) и акцентный цвет текста. Главный цвет бренда. |
| Акцент — красный вариант | `#EF281A` | Более «красный» оттенок, встречается на hover/вторичных акцентах. |
| Акцент — коралл (светлее) | `#EF714D` | Светлый вариант акцента, для подсветок/градиента. |
| **Текст основной** | `#212121` | Почти-чёрный. Заголовки и body. Не используют чистый `#000`. |
| Текст приглушённый | `#8A8A8A` | `rgb(138,138,138)` — подписи, второстепенный текст. Ещё встречается `#909090`. |
| **Фон основной** | `#FFFFFF` | Белый — доминирующий фон. |
| Фон секций (светлый) | `#F4F4F4` | Чередующиеся секции, карточки. |
| Фон/границы (серый) | `#EBEBEB` | Разделители, рамки, фон блоков. Светлее — `#E5E5E5`, `#E8E8E8`. |
| Чёрный (редко) | `#000000` | Точечно, для максимального контраста. |

Частотность в разметке (грубый вес использования): `#FFFFFF` ≫ `#212121` ≫ `#EBEBEB` > `#F4F4F4` > `#EC582E` — то есть 90% страницы это бело-серо-чёрная база, а рыжий — точечный акцент. **Не заливать акцентом большие площади** — он работает именно как редкое пятно (кнопки, ключевые слова, иконки).

### Акцентная шкала (для Mantine `colors`, 0→9)

Построена вокруг базового `#EC582E` (база = индекс 6):

```
0  #FFF0EB
1  #FFE0D6
2  #FFC0AD
3  #FF9D80
4  #F97D57   (≈ коралл #EF714D с сайта)
5  #F26538
6  #EC582E   ← основной акцент
7  #D9431C
8  #B3360F   (hover/active — темнее базы; на сайте для красноты есть #EF281A)
9  #8F2A0A
```

## 2. Типографика

**Шрифт лендинга:** `RandomGrotesque`, fallback `Arial, sans-serif`.
Это коммерческий display-grotesque (тесный, жирный, с характером). Для нашего проекта, если лицензии на RandomGrotesque нет, берём близкий по характеру бесплатный grotesque и сохраняем фирменный приём (тесный интерлиньяж + отрицательный трекинг на крупных заголовках).

**Рекомендуемые бесплатные фолбэки** (по убыванию похожести характера): `Onest`, `Manrope`, `Inter Tight`, `Geist`. Стек по умолчанию:
```
font-family: "RandomGrotesque", "Onest", "Manrope", system-ui, -apple-system, Arial, sans-serif;
```

**Начертания:** `400` (body), `600` (заголовки — доминирующий вес), `700` (усиленный акцент). Курсив/тонкие веса не используются.

**Фирменный приём заголовков (важно — это «лицо» бренда):**
- очень тесный интерлиньяж: `line-height: 0.8` на крупных дисплейных заголовках (1.2–1.4 на body);
- отрицательный трекинг: `letter-spacing: -1px … -3px` (чем крупнее кегль — тем сильнее минус);
- вес `600`;
- регистр обычный (sentence/Title case), **без `text-transform: uppercase`** (на сайте 0 использований).

**Шкала кеглей (px, реальные с сайта):**

| Назначение | Размер | LH | Weight | Tracking |
|---|---|---|---|---|
| Hero / display | 60–100 | 0.8 | 600 | −2…−3px |
| H1 / крупные заголовки | 42 | 0.8–1.0 | 600 | −1…−2px |
| H2 | 30–36 | 1.0–1.2 | 600 | −0.5…−1px |
| H3 / подзаголовок | 20–24 | 1.2 | 600 | 0 |
| Body | 16 | 1.4 | 400 | 0 |
| Small / подписи | 13–14 | 1.4 | 400 | 0 |

## 3. Форма и скругления

Элементы заметно скруглены. Реальные радиусы с сайта (по частоте): `15px`, `30px`, `20px`, `10px`, `40px`, иногда `0`.

| Элемент | border-radius |
|---|---|
| Кнопки (CTA) | `30–40px` (почти pill) |
| Карточки / блоки | `15–20px` |
| Мелкие элементы / инпуты | `10–12px` |
| Острые секции (по месту) | `0` |

**Токены радиусов:** `sm: 10px`, `md: 15px`, `lg: 20px`, `xl: 30px`, `pill: 40px`.

---

## 4. Кнопки и компоненты

**Primary CTA** (`Записаться на консультацию` и т.п.):
- фон `#EC582E`, текст `#FFFFFF`, вес `600`;
- скругление `30–40px` (pill);
- крупный паддинг (`~20px` по вертикали, `~40px` по горизонтали);
- hover — затемнение акцента (шкала индекс 7–8).

**Secondary** — обычно контурная/светлая кнопка на сером фоне или текст-ссылка.

**Карточки кейсов/метрик** — белые или `#F4F4F4` на белом, радиус `15–20px`, крупная цифра (display-кегль) + мелкая подпись `#8A8A8A`. Большие числа-результаты — ключевой визуальный приём лендинга.

---

## 5. Лейаут и ритм

- Контентные секции на всю ширину, чередование фона `#FFFFFF` / `#F4F4F4`.
- Много воздуха между блоками, крупные вертикальные отступы.
- Сетка Tilda (контейнер ~1200px). Для нас — обычный центрированный контейнер с щедрыми gap'ами.
- Иконки — SVG, монолинейные/минималистичные.

## 6. Тон и контент

- Голос: уверенный, на результат, по делу. Заголовки-обещания: «Станьте лидером своей ниши».
- Социальное доказательство цифрами: суммарные подписчики, «золотые/серебряные кнопки», метрики каналов — крупно и заметно.
- Минимум декора, максимум смысла и контраста.

### Mantine theme (заменить текущий объект в `src/app/layout.tsx`)

Сейчас там `primaryColor: "blue"` и системный шрифт — меняем на бренд:

```ts
import { createTheme } from "@mantine/core";

export const theme = createTheme({
  primaryColor: "brand",
  primaryShade: 6,
  colors: {
    // 0 → 9
    brand: [
      "#FFF0EB", "#FFE0D6", "#FFC0AD", "#FF9D80", "#F97D57",
      "#F26538", "#EC582E", "#D9431C", "#B3360F", "#8F2A0A",
    ],
  },
  fontFamily:
    '"RandomGrotesque", "Onest", "Manrope", system-ui, -apple-system, Arial, sans-serif',
  headings: {
    fontFamily:
      '"RandomGrotesque", "Onest", "Manrope", system-ui, Arial, sans-serif',
    fontWeight: "600",
  },
  defaultRadius: "md", // 15px-ish; для CTA-кнопок ставить radius="xl"
  radius: { sm: "10px", md: "15px", lg: "20px", xl: "30px" },
  black: "#212121",
});
```

> Примечание: фирменный «тесный» вид заголовков (`line-height: 0.8`, `letter-spacing` в минус) Mantine из коробки не задаёт — добавлять на крупных Title/heading вручную через `styles`/CSS-классы.
